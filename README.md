# Prop Radar

A single-page iPhone Safari app that turns the phone into a "GAYDAR" targeting scope prop: face detection, proximity beeping, lock-on, a scan sequence and a gyro sweep.

- App: [`docs/index.html`](docs/index.html), served by GitHub Pages from `/docs`.
- Plan: [`prop-radar-handoff-plan.md`](prop-radar-handoff-plan.md).

Phase order: 1 core app, 2 gyro sweep, 3 8BitDo Zero 2 controller (done; button map in `CONFIG.keys` / `CONFIG.pad`).
